# Observatório SAGASP

Páginas públicas do Observatório do setor do [SAGASP](https://sagasp.com) — comércio atacadista de gêneros alimentícios no estado de São Paulo.

Geradas automaticamente a partir de dados oficiais (Receita Federal, Novo CAGED/MTE, RAIS). Atualização mensal.

- `index.html` — porta de entrada
- `empresas.html` · `vinculos.html` · `empregos.html` · `perfil.html` — os 4 temas
